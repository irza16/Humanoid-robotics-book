# Assignments

This section contains assignments for Module 3.

## Assignment 1: Create a Scene in Isaac Sim
- **Objective**: Create a simple scene in Isaac Sim with a robot and some objects.
- **Tasks**:
  1. Create a new stage in Isaac Sim.
  2. Add a ground plane and some basic shapes (e.g., cubes, spheres).
  3. Import a robot model (e.g., from the included assets).
  4. Save the stage.

## Assignment 2: Generate Synthetic Data
- **Objective**: Use Isaac Sim to generate a synthetic dataset for object detection.
- **Tasks**:
  1. Create a scene with a robot and several objects.
  2. Add a camera to the robot.
  3. Use the Unity Perception package to generate bounding box labels for the objects.
  4. Run the simulation and save the generated dataset.

## Assignment 3: Run an Isaac ROS Gem
- **Objective**: Use an Isaac ROS gem to perform a perception task.
- **Tasks**:
  1. Create a ROS 2 launch file that starts a camera node and the `isaac_ros_apriltag` node.
  2. Run the launch file and visualize the detected AprilTags in RViz2.
